# VocaClear — 보카클리어 고교필수편 단어 암기

백준(BOJ) 스타일의 깔끔한 정적 웹앱. 보카클리어 고교필수편 **DAY 20 ~ DAY 40** 단어 840개를
한국어 뜻 제시 → 영단어 맞히기 방식으로 학습/테스트할 수 있습니다.

## 기능

- 단어장: Day별 목록 · 진행률 표시
- 학습: 뜻 보고 정답 뒤집기 카드 (키보드 지원)
- 테스트: Day별 10/20/40문항 또는 전 Day 랜덤, 오답 재시험
- 진행률은 브라우저 localStorage에 저장
